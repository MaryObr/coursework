# Coursework
materials and code for my 3d year coursework

Здесь собраны скраулеренные отзывы, разметка их тремя аннотаторами, тетрадка с кодом, рисунки.

Если вы хотите посмотреть на изначально собранные отзывы в разной степени необработанности, обратитесь к папкам raw_data и raw_second_site.

Если хотите посмотреть отдельно на базы данных различных аннотаторов, обратитесь к папке annotators.

Если хотите посмотреть на код курсовой, скачайте Coursework.ipnb, здесь тетрадка не полностью отображается. Внутри тетрадки следующие разделы:

  1) Первичный сбор данных
  2) Обработка первичных данных
  3) Добор саркастических данных
  4) Доработка датасета -- впоследствии от этой идеи отказались
  5) Сведение разметчиков в одну базу
  6) Согласие разметчиков
  7) Типы сарказма
  8) Выборка для обучения
  9) Дообучение модели BERT
  10) Метрики на данных со смешанным согласием
  11) Интерпретация того, что значимо для модели
  12) Классификация данных GPT4 (объяснения GPT4 можно посмотреть в файле gpt.txt)

Если хотите посмотреть на графики, иллюстрирующие графики, обратитесь к папке graphs.

Финальную версию базы данных с разделением на тест и трейн и аннотацией сферы деятельности сарказма можете найти в reviews_final.db
Csv-файлы выборок можете найти в папке train_test_val

Дообученную модель можно найти на huggingface: https://huggingface.co/MaryObr/sarcasm-RuBERT
